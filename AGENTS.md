# Agent routing

Read root README → docs/README.md → relevant requirements/architecture/reference → skills/<name>/SKILL.md → target repository's own source, tests and scientific validation.

Follow [portable documentation standard](docs/governance/documentation-architecture.md) and [local profile](docs/governance/documentation.md). One fact, one authoritative home. Research/proposals are not shipped behavior. Never claim tests, scientific validity or System compatibility without execution. No large framework, new scheduler or duplicate evaluator without reuse assessment.

Target code, checkpoints and datasets remain protected and unchanged unless explicitly authorized. Always separate observations, hypotheses, interventions and verified results. Fail closed on missing provenance; holdout is independent and not a repeated tuning oracle.
