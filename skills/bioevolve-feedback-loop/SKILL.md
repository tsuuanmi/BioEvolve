# bioevolve-feedback-loop

## Required input
An authorized, pinned external target or artifact, relevant evidence, and a defined scientific question. Use only approved data and evaluator.

## Procedure
1. Verify hypothesis, intervention and evaluation references with provenance.
2. Compare measurements to predicted effect and falsification criteria.
3. Mark accept-for-review, reject, investigate or blocked; explain regressions and unexpected results.
4. Preserve negative and inconclusive experiments, identify repeated failed approaches, and suggest one bounded next hypothesis or stop.
5. Return feedback artifact. Scientific approval remains with domain owner; no silent retry or auto-merge.

## Output contract
Return structured, evidence-linked artifacts as specified in [BioEvolve contracts](../../docs/reference/artifacts.md). Include blockers and uncertainties explicitly; do not claim unexecuted work.
